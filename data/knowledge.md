# 我的 RAG 项目（示例知识文档）

## 项目定位

RAG 问答系统 V1.0 的目标是：能回答基于本地文档的问题；当本地文档找不到答案时，自动调用搜索引擎查找并总结。回答需要带引用来源，方便用户核实。这是 Agent 的雏形，核心是「工具调用」的思想——从被动回答问题，变成主动决定要不要调用外部工具。

## 什么是 RAG

RAG 是 Retrieval-Augmented Generation（检索增强生成）的缩写。基本流程是：先把文档切成小块，用 Embedding 模型把每块文本变成向量；用户提问时，把问题也变成向量，找到最相似的几个片段；最后把这些片段作为上下文交给大模型，生成回答。这样做的好处是：答案有依据、可以引用来源、模型不用记住所有知识。

## 四周计划

第一周：学 Python 基础并跑通最简 RAG，实现「读本地文档 → 问答」。
第二周：接入搜索引擎，实现智能路由：本地检索无结果时自动搜索并总结。
第三周：用 Streamlit 做网页界面，回答中标注引用来源。
第四周：整理代码、写 README、上传 GitHub。

## 技术选型

编程语言使用 Python；框架以 LangChain 为主，但以能实现功能为准，不绑定死；Embedding 模型先用本地开源模型 BAAI/bge-small-zh-v1.5；向量检索先直接用 NumPy 算相似度，之后可以升级为 FAISS 或 Chroma。
