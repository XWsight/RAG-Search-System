# 可观测性与运维

## 健康检查

存活检查只回答进程是否能够响应，不应访问昂贵外部服务。就绪检查用于判断实例能否接收流量，应验证本地持久层、目录结构和关键依赖状态。可选云模型暂时不可用可以标记降级，但本地数据根不可写应判定为未就绪。

## 指标与日志

指标名称应保持低基数，租户 ID、知识库 ID、问题正文和文件名不能成为 Prometheus 标签。结构化日志使用允许字段白名单，并通过 trace ID 与 request ID 关联请求；日志不得记录 API Key、完整文档或原始上游响应。

## 一致性备份

备份必须把 SQLite 数据库、原始文档和向量目录视为一个一致性单元。安全流程是先停止写入，确认服务退出，再复制整个存储根并生成校验摘要。只备份 catalog 而遗漏文档或向量集合，恢复后会产生不可修复的引用断裂。

## 单实例租约

同一存储根只能由一个写入进程持有。启动时获取跨进程文件租约，第二个实例应立即失败；关闭时按顺序停止接收请求、等待任务、关闭索引和数据库，最后释放租约。仅靠约定 Uvicorn worker 数量不能代替运行时保护。
