# 检索增强生成

RAG 是 Retrieval-Augmented Generation 的缩写，中文通常称为检索增强生成。系统先从外部知识库检索与问题相关的证据，再让生成模型依据证据组织回答。它把模型参数之外、可以独立更新的资料引入回答流程，因此比只依赖模型内部记忆更容易追踪来源。

一个常见流程包括文档解析、文本切分、向量化、建立索引、检索、重排序、提示词组装、生成和引用校验。证据不足时，系统应拒绝编造，或在用户明确允许后补充网络来源。

RAG 不能自动保证事实正确。检索可能漏掉相关资料，资料本身也可能错误，生成结果还可能错误引用。因此需要分别评估检索召回率、排序质量、路由准确率、答案忠实度和引用覆盖率。
